About TaskFlow

TaskFlow is a lightweight, browser-based task management application built as part of the DevOps Fundamentals course (Spring 2026) at the University of Central Punjab.


Purpose

The app demonstrates a full CI/CD pipeline using GitHub Actions, Docker Hub, and Render. Every page was developed on a separate Git feature branch and merged via Pull Request.


How to Use

  • Go to Home to see your task summary.
  • Click Add Task to create a new task.
  • Use Task List to view and filter all tasks.
  • Click a task to see its full Task Detail.
